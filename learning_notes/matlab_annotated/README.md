# MATLAB日本語解説付きコピー

このフォルダは学習用です。元のMATLABコードは変更せず、各 `.m` ファイルの全行を残したうえで、日本語コメントを差し込んだコピーを置いています。

## 読む順番のおすすめ

1. `main.m`
2. `bssAuxFdica.m`
3. `permSolverCor.m` / `permSolverIps.m` / `permSolverDoa.m`
4. `getInputFileNames.m`
5. `DGTtool.m`
6. `bss_eval/` 以下

## 注意

- これは実行用ではなく理解用です。
- 空行と元からあるコメントには、重複する追加解説を付けていません。
- 実行コードの解説では、文法だけでなく、代入される値、主なshape、処理が必要な理由、アルゴリズム内での役割を示します。
- 日本語コメントは学習補助です。数式の導出や個々のshapeは、質問に応じて元コードと対応付けて詳しく確認します。
- 元コード本体は変更していません。
