## 必ず区別する差異

- 白色化: MATLAB原文はDを削減次元へ切り詰めない。Pythonは上位固有値を選択し下限を設ける。
- AuxFDICA: Pythonは対角正則化と特異行列時のpinv分岐を追加。音源更新中の重みは両版とも固定。
- コスト: Pythonは行列式の絶対値にもeps下限を設ける。
- Projection back: MATLABの右除算とPythonのpinvは、特にランク落ち時に同一とは限らない。
- COR: 局所相関配列の格納・平均、自己周波数の除外、ゼロ分母の扱いに差がある。
- DOA: クラスタ初期化とDC・無効値の扱いが異なる。
- IPS: 候補の探索順が異なり、同点の場合に結果が変わり得る。
- STFT/ISTFTと描画: 機能単位の対応であり、処理の全行が一対一に対応するわけではない。
